# 輪盤策略模擬器

[English Version](README.md)

### 簡介
這是一個輪盤賭場策略模擬器，用於測試和比較不同的下注策略。使用者可以選擇不同的策略、下注類型和下注方式，並即時觀察資金變化。

### 功能特點
- **多種策略選擇**：
  - 馬丁賭法：輸局後下注翻倍，贏局後重置
  - 反馬丁賭法：贏局後下注翻倍，輸局後重置
  - 斐波那契數列法：根據斐波那契數列調整下注金額

- **多樣下注類型**：
  - 直注：選擇單一數字（賠率 1:35）
  - 分注：選擇相鄰兩個數字（賠率 1:17）
  - 角注：選擇四個交叉點數字（賠率 1:8）
  - 紅黑/奇偶：選擇紅色或黑色（賠率 1:1）

- **下注方式**：
  - 隨機下注：每次下注隨機選擇數字/顏色
  - 固定下注：維持相同的下注內容

- **即時視覺化**：
  - 資金變化曲線圖
  - 詳細的回合數據
  - 關鍵指標即時更新

- **自訂參數**：
  - 初始本金
  - 初始下注金額
  - 最大回合數

- **其他功能**：
  - 中英文界面切換
  - 模擬速度調整
  - 數據導出（CSV格式）

### 安裝與執行
1. 安裝必要套件：
```bash
pip install -r requirements.txt
```

2. 執行應用：
```bash
streamlit run app.py
```

### 使用說明
1. 在側邊欄選擇策略、下注類型和下注方式
2. 設定初始本金、下注金額和回合數
3. 點擊「開始模擬」按鈕
4. 觀察資金變化和統計數據
5. 可隨時調整模擬速度
6. 模擬結束後可下載詳細數據

### 注意事項
- 本模擬器僅用於教育目的
- 實際賭場的輪盤遊戲可能會有不同的規則和賠率
- 請理性看待模擬結果，不要將其作為實際賭博的參考
